STEP 01

Download & Extract

Begin by downloading the beta package. It comes as a compressed ZIP file.

Crucial: You must extract (unzip) the contents to a folder that you won't delete. The browser needs to read these files every time it starts.

Tip: Look for manifest.json inside the folder to confirm it's correct.
nova.zip
Browser Address Bar
chrome://extensions
Press Enter
STEP 02

Extension Management

Open Google Chrome or any Chromium-based browser. In the address bar, type:
chrome://extensions

This page manages all installed plugins. You need to be here to install a manual "unpacked" extension.

STEP 03

Activate Developer Mode

Look at the top-right corner of the Extensions page. You will see a toggle switch labeled Developer mode.

Turn this ON. This reveals the "Load unpacked" button.

STEP 04

Load the Core

Click the newly visible Load unpacked button. A file picker will open.

Navigate to inside the folder you created in Step 1. Select the top-level directory.

STEP 05

Pin & Launch

Click the "Puzzle Piece" icon in your Chrome toolbar.

Find Nova Beta and click the 📌 Pin icon.
